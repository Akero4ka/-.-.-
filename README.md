## Запуск C++

Каждый файл содержит собственный `main`. Собирайте один выбранный файл, а не все сразу. Исходники сохранены в UTF-8.

GCC:

```sh
g++ -std=c++17 "Практическая работа 1/task_1.cpp" -o task
```

В PowerShell запустите `./task.exe`, в Linux/macOS — `./task`. В терминале разработчика Visual Studio:

```bat
cl /nologo /EHsc /std:c++17 /utf-8 "Практическая работа 1\task_1.cpp" /Fe:task.exe
task.exe
```

Форматы ввода, примеры и трактовки неоднозначных условий приведены в README каждой работы. Предполагается корректный ввод из описанных диапазонов. Проекты `.sb3` запускаются в Scratch.
