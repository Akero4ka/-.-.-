# Практическая работа 1

Каждый `task_N.cpp` — самостоятельная программа C++17. Данные вводятся без приглашений. В примерах символ `/` разделяет строки.

| Файл | Задача | Вход | Пример входа | Результат |
| --- | --- | --- | --- | --- |
| [task_1.cpp](task_1.cpp) | Обмен без третьей переменной | Два целых a b | `4 5` | `5 4` |
| [task_2.cpp](task_2.cpp) | Произведение факториалов за один цикл | Неотрицательное n | `4` | `288` |
| [task_3.cpp](task_3.cpp) | Значение без условий | A = 0 или 1 | `0` | `2` |
| [task_4.cpp](task_4.cpp) | Слияние за один цикл | n m, затем два отсортированных массива | `3 2 / 1 4 8 / 2 5` | `1 2 4 5 8` |
| [task_5.cpp](task_5.cpp) | Пропущенное число | n, затем n различных чисел от 0 до n | `4 / 0 1 4 2` | `3` |

Обмен в задаче 1 использует только присваивания и арифметику; разность a − b должна помещаться в `long long`. Для задачи 2 точный результат помещается в `unsigned long long` при 0 ≤ n ≤ 8; далее выводится `Overflow`. При n = 0 пустое произведение равно 1. Слияние выполняется одним циклом после чтения массивов. В задаче 5 используется XOR, без вычисления суммы.

Сборка и запуск описаны в [общем README](../README.md).
