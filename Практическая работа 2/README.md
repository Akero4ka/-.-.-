# Практическая работа 2

Проекты открываются в Scratch через меню «Файл → Загрузить с компьютера». Запуск — зелёным флагом. Внешние расширения не нужны.

1. Спортсмен и аплодисменты: исходный [проект](../Проект%20Scratch.2pr.sb3) уже был в репозитории и сохранён.
2. [Угадывание числа](task_2.sb3): загадайте целое от 1 до 1023. На предложение числа введите 0, если оно угадано, 1, если ваше число меньше, или 2, если больше. Используется двоичный поиск, не более 10 попыток. Некорректный ответ запрашивается снова; противоречивые ответы завершают игру сообщением.
3. [Перевод в двоичную систему](task_3.sb3): сначала основание 1–10, затем неотрицательная целочисленная запись без пробелов и знака. Для основания 1 вводится непустая строка единиц: `11111` означает 5 и даёт `101`. Для основания 3 запись `102` даёт `1011`. Для основания 10 число `0` даёт `0`. Неверные цифры отклоняются. Максимальное точное число — 9007199254740991, ограничение числового типа Scratch.

Проект обмена переменных [Проект Селезнев Scratch](../Проект%20Селезнев%20Scratch.sb3) сохранён в корне репозитория.
