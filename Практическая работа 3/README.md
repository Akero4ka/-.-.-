# Практическая работа 3

Каждый `task_N.cpp` — самостоятельная программа C++17. Данные вводятся без приглашений. В примерах символ `/` разделяет строки.

| Файл | Задача | Вход | Пример входа | Результат |
| --- | --- | --- | --- | --- |
| [task_1.cpp](task_1.cpp) | Гипотенуза | Два положительных катета | `3 4` | `5` |
| [task_2.cpp](task_2.cpp) | МКАД | Целая скорость v, неотрицательное время t | `-1 1` | `108` |
| [task_3.cpp](task_3.cpp) | Цифра десятков | Неотрицательное целое число | `123` | `2` |
| [task_4.cpp](task_4.cpp) | Следующее чётное без условий | Целое n | `-3` | `-2` |
| [task_5.cpp](task_5.cpp) | Электронные часы | Неотрицательное количество секунд | `3661` | `1:01:01` |
| [task_6.cpp](task_6.cpp) | Обмен без третьей переменной | Два целых числа | `12 -5` | `-5 12` |
| [task_7.cpp](task_7.cpp) | Улитка | Положительные целые h a b | `10 3 2` | `8` |
| [task_8.cpp](task_8.cpp) | Симметрия четырёх цифр | Число от 0 до 9999 | `1221` | `1` |
| [task_9.cpp](task_9.cpp) | Делимость без условий | Два натуральных числа | `12 3` | `1` |
| [task_10.cpp](task_10.cpp) | Максимум только арифметикой | Два числа от 1 до 1000 | `20 7` | `20` |

Задачи 4, 8 и 9 не используют ветвлений и циклов. Задача 10 использует только целочисленную арифметику и присваивания. В задаче 6 обмен выполнен через XOR. Часы переходят к следующим суткам после 23:59:59. Для следующего чётного результат и промежуточное n + 2 должны помещаться в `long long`. Если улитка не может достичь вершины, выводится `Impossible`. В задаче 9 числа натуральные; их остатки и произведение остатков должны помещаться в `long long`.

Раздел методички про указатели содержит учебные примеры, но отдельной задачи не задаёт.

Сборка и запуск описаны в [общем README](../README.md).
