# Практическая работа 5

Каждый `task_N.cpp` — самостоятельная программа C++17. Данные вводятся без приглашений. В примерах символ `/` разделяет строки.

| Файл | Задача | Вход | Пример входа | Результат |
| --- | --- | --- | --- | --- |
| [task_1.cpp](task_1.cpp) | Рост объёма за день | Положительные действительные X Y | `100 121` | `3` |
| [task_2.cpp](task_2.cpp) | Минимальная последовательность команд | Натуральные A > B | `10 3` | `:2 / -1 / -1` |
| [task_3.cpp](task_3.cpp) | Уход соседних групп | N ≤ 1000, затем N номеров от 0 до 9 | `6 / 1 2 3 3 2 1` | `6` |

В задаче 1 используется объём за текущий день, а не сумма за все дни. Несмотря на фразу «более Y» в описании, выбран явно заданный критерий вывода: достигнуть или превысить Y. Возможны обычные округления вещественной арифметики.

В задаче 2 вычитание разрешено и для чётного числа, если деление приведёт ниже B: иначе, например, 4 нельзя преобразовать в 3. Это трактовка, совместимая с требованием получить любое натуральное B < A.

В задаче 3 все группы длиной не менее двух уходят одновременно за раунд. Затем поиск повторяется. Например, `1 2 2 1` даёт 4, а `1 1 2 2 1` даёт 4: последний студент остаётся.

Сборка и запуск описаны в [общем README](../README.md).
