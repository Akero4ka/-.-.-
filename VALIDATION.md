# Проверка решений

Проверка выполнена 3 ноября 2026 года.

- Все 24 программы C++ собраны MSVC 14.44 в режиме C++17 с `/W4`. Новые 21 исходник собраны без предупреждений; три исходника работы №6 извлечены из существующего архива без изменений.
- Пройдено 1343 проверки C++: примеры, пустые массивы, отрицательные значения, переполнение произведения факториалов, случайные массивы, симметрия, делимость, часы, рекурсивный НОД и допустимость каждого перекладывания ингредиентов.
- Для задачи №5.2 число команд сравнивалось с независимым динамическим поиском оптимального решения для всех 1 ≤ B < A ≤ 31.
- Проверены структура JSON и ссылки между блоками двух новых Scratch-проектов. Через тестовый интерпретатор используемых блоков выполнены 1529 проверок: все числа от 1 до 1023 для угадывания, преобразование малых чисел при каждом основании 1–10 и отклонение неверных записей.

Scratch-проекты не запускались в графическом редакторе; автоматическая проверка относится к структуре и логике блоков. Исходные PDF, ZIP и два SB3 сохранены побайтово. Исполняемые файлы и временные файлы сборки не включены в репозиторий.
