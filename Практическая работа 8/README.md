# Практическая работа 8

Каждый `task_N.cpp` — самостоятельная программа C++17. Данные вводятся без приглашений. В примерах символ `/` разделяет строки.

| Файл | Задача | Вход | Пример входа | Результат |
| --- | --- | --- | --- | --- |
| [task_1.cpp](task_1.cpp) | Быстрое возведение в степень | Основание a и целая степень n | `10 12` | `1000000000000` |
| [task_2.cpp](task_2.cpp) | Рекурсивный НОД | Натуральные a b ≤ 10^9 | `9 12` | `3` |
| [task_3.cpp](task_3.cpp) | Перекладывание ингредиентов | Неотрицательное целое n | `2` | `Ingredient 1 move from 1 to 2 / Ingredient 2 move from 1 to 3 / Ingredient 1 move from 2 to 3` |

Быстрое возведение реализовано рекурсивной функцией с O(log |n|) умножений. Поддерживаются отрицательные степени; 0^0 принято равным 1, ноль в отрицательной степени даёт `Undefined`. Результат вещественный, с округлением; бесконечность обозначается `Overflow`.

НОД вычисляется рекурсивным алгоритмом Евклида. В задаче 3 ингредиенты переносятся с первой салфетки на третью. Вывод содержит 2^n − 1 строк, поэтому для запуска выбирайте небольшое n; при n = 0 вывод пуст.

Сборка и запуск описаны в [общем README](../README.md).
